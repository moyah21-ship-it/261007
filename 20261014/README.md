# 금융소비자보호위원회 의사록 자동작성 PoC

녹취 텍스트를 넣으면 AI가 안건별 요지·발언·처리 결과·후속조치를 뽑아냅니다. 업무규칙(R1~R14)으로 검증하고 담당자가 확정하면, 의사록 양식(.docx)으로 내려받을 수 있는 웹앱입니다.

> ⚠️ 교육용 PoC입니다. **가상(더미) 자료만** 사용하세요. 실제 회사자료·개인정보·고객정보는 넣지 않습니다.

## 1. 실행 방법

**Windows**: 폴더에서 `run.bat`을 더블클릭합니다. 처음 실행할 때 필요한 패키지를 자동으로 설치하고, 끝나면 브라우저가 열립니다.

**직접 실행**
```bash
pip install -r requirements.txt
streamlit run app.py
```
브라우저에서 http://localhost:8501 이 열립니다.

**API 키 (선택)**: `.env.example`을 `.env`로 복사하고 `ANTHROPIC_API_KEY=`에 키를 넣습니다. 키가 없으면 **모의 모드**로 동작합니다. 모의 모드는 정답데이터를 AI 결과 대신 쓰는 방식이며, 화면·검증·출력 흐름은 AI 모드와 같습니다.

## 2. 사용 순서

| 탭 | 하는 일 | 관련 요구사항 |
| --- | --- | --- |
| ① 회의 개요 | 재적·출석·불참·이석·정족수 확인, 녹취록 파싱 결과(매핑 실패 줄은 빨간색) | FR-01~04 |
| ② AI 추출 | [AI 분석 실행] 또는 [모의 결과 불러오기], 안건별 결과와 원문 대조 | FR-05, 06 |
| ③ 규칙 검증 | R1~R14 경고·정보 목록 | FR-07 |
| ④ 검토·출력 | 표에서 직접 수정 → 확정 → 의사록 .docx 다운로드, 정답 예시와 비교 | FR-08~11 |
| ⑤ 화자 매핑 | '화자1, 화자2'로만 된 녹취록의 화자를 위원에 매핑 제안·확정 | FR-13 |

사이드바에서 정족수·가결 기준 값을 바꿀 수 있습니다(FR-12). 기본값은 `settings.json`에 있습니다.

## 3. 폴더 구조

```
app.py                 Streamlit 화면
core/
  config.py            설정값(정족수·가결 기준, 모델, 경로)
  loader.py            CSV·녹취록 읽기, 발언자 매핑 (R11)
  meeting.py           회의 개요 계산 (R1, R3, R13)
  extractor.py         Claude API 추출 + 모의 모드, JSON 오류 시 1회 재요청
  rules.py             업무규칙 검증 R1~R14
  render.py            의사록 양식(.docx) 채우기, 초안/확정 표시 (R14)
  compare.py           정답 예시와 비교
  speakers.py          화자번호형 녹취록 매핑 제안
prompts/extract_prompt.md   AI 지시문 (문체·규칙을 여기서 고칩니다)
data/                  더미데이터 01~08 + mock_result.json
output/                생성된 의사록이 저장되는 곳
tests/                 자동 테스트 (python -m pytest -q)
tools/make_mock.py     정답데이터 → 모의 결과 변환
```

## 4. 업무규칙 요약

R1 개회 정족수 · R2 의결 요건 · R3 이석 반영 · R4 표결 합계 · R5 안건 유형별 결과 · R6 발언 분류 · R7 정정 발언 · R8 상대 날짜 환산 · R9 후속조치 완결성 · R10 원문 근거 · R11 발언자 매핑 · R12 출석 이상 · R13 기본 통계 · R14 담당자 확정

정족수·가결 기준(재적 과반 출석, 출석 과반 찬성)은 **교육용 가정값**입니다. 실제 운영규정에 맞게 `settings.json`을 수정하세요.

## 5. 다른 회의에 쓰려면

`01~03` CSV와 녹취록 TXT를 같은 형식으로 만들어 사이드바에서 업로드합니다. 녹취록은 한 줄에 한 발언씩 `[14:00:05] 직책 이름: 발언` 형식으로 씁니다. 모의 모드는 기본 더미 회의에서만 의미가 있으므로, 다른 회의는 AI 모드로 분석합니다.

## 6. 문제 해결

- **파일 인코딩 오류**: CSV는 UTF-8 또는 CP949로 저장합니다. 문서보안(DRM)으로 암호화된 파일은 읽을 수 없습니다.
- **AI 응답 오류**: 사이드바에서 모의 모드로 바꿔 시연을 이어갈 수 있습니다.
- **모델 이름 오류**: `.env`의 `ANTHROPIC_MODEL` 또는 `settings.json`의 `model`을 사용 가능한 모델로 바꿉니다.
